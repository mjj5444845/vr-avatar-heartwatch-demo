# Demo Script

## One-minute Walkthrough

1. Open the demo page.
2. Click **Start sensor** to begin mock Apple Watch streaming.
3. Point out the VR avatar and its changing aura color.
4. Explain that each heart-rate sample creates an avatar response.
5. Click **Log VR event** to simulate a user interaction inside VR.
6. Show the dashboard table, event feed, and chart.
7. Click **Export JSON** to show that records are being captured.

## Story

The avatar does not just wait for commands. It senses the user's physiological state and adapts the interaction style: calm, active, supportive, or grounding.
